# Zoody: Sky Crystal Run

A lightweight browser game starring Zoody the dragon.

## Run locally

```bash
npm install
npm run dev
```

## Deploy

This project is ready for Vercel. Import the repository and deploy with the default settings.

## Controls

- Arrow keys / WASD: move
- Mobile: on-screen controls

Collect sky crystals, avoid fireballs, protect your hearts, and chase a higher score.
